# AI-Data-Analyst
AI-powered Data Analyst built with Streamlit and Azure OpenAI. Upload datasets, ask questions in natural language, and get instant insights, charts, and explanations
### 🔐 API Configuration

The app supports two modes:

1. **Default Mode**  
   Uses pre-configured Azure OpenAI credentials (via Streamlit Secrets)

2. **Custom API Mode**  
   Users can optionally provide their own:
   - Azure Endpoint
   - API Key
   - Deployment Name

This allows flexibility for testing with personal API access.
